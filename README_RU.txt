ARAIK STORE WEB — версия 0.1.0

ЧТО ЭТО
Статический веб-каталог/PWA. Включает адаптивный интерфейс, поиск, категории,
избранное (сохраняется в браузере) и базовую офлайн-оболочку.

ВАЖНО
Это пока только веб-каталог. Он НЕ подписывает IPA, НЕ устанавливает приложения
и НЕ взаимодействует с Apple ID, pairing или LocalDevVPN. Обычный сайт/PWA
не получает системные полномочия iOS для установки произвольных IPA.
DNS-профиль не заменяет механизм подписи.

ЗАПУСК
1. Распакуйте архив.
2. Разместите содержимое папки на HTTPS-хостинге (например, статический хостинг).
3. Откройте HTTPS-адрес в Safari на iPhone.
4. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
5. Для локального теста можно открыть index.html на компьютере, но PWA и
   Service Worker полноценно работают через HTTPS или localhost.

РЕДАКТИРОВАНИЕ КАТАЛОГА
Откройте app.js и измените массив apps в начале файла.
Сейчас карточки FileBox, Pixel Run и QuickNote — демонстрационные записи,
не ссылки на реальные IPA.

ФАЙЛЫ
index.html           Главная страница
styles.css           Дизайн и адаптивная вёрстка
app.js               Каталог, поиск, фильтры, избранное
manifest.webmanifest PWA-манифест
sw.js                Кэширование для офлайн-оболочки
icons/               Иконки PWA

Для реальной установки IPA потребуется отдельный нативный/поддерживаемый
компонент установки и подписи. Не собирайте пароли Apple ID или коды 2FA
на веб-сайте; авторизация должна проходить через доверенный механизм Apple.
